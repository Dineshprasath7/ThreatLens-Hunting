API reference

Local JSON API for classifying structured NSL-KDD connection records. Base URL: http://127.0.0.1:5000. Start it with run.bat -Mode Serve.

Endpoints

MethodPathPurpose
GET/healthReturns {"status":"ready"} (200) or model_missing (503).
GET/schemaLists the 41 required features and categorical fields.
GET/metricsReturns saved held-out evaluation metadata; 503 without a model.
GET/predictOpens the browser demo.
POST/predictClassifies one JSON object or an array of 1–100 objects.
GET/mitreShows category-to-technique associations and hunting notes.

POST /predict

Set Content-Type: application/json. Supply every feature below. Key order does not matter. Categorical values are strings; other fields are finite, nonnegative numbers. Rate fields must be between 0 and 1. protocol_type accepts tcp, udp, or icmp. Unknown service or flag strings can be supplied, but prediction quality for unseen values is uncertain.

Response fields

resultsOne result per input record, in input order.
predictionNormal, DoS, Probe, R2L, or U2R.
confidenceMaximum Random Forest vote proportion (0–1); not calibrated certainty.
probabilitiesPer-class vote proportions.
severityProject-defined triage level.
mitre_attackIllustrative technique ID, name, URL, and mapping type; null fields for Normal.

Possible errors

400 invalid JSON shape or features; 415 non-JSON content type; 503 model missing.
